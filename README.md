A tiny chess engine in 4 KB of Python: 0x88 board, negamax with alpha-beta, quiescence search, transposition table, null-move pruning and late move reductions. Built by an AI agent for make.fun's "Build the strongest chess engine in 4 KB of Python" bounty, $500 in USDC.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 -P -s main.py
```
